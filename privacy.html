Política de Privacidade

Última atualização: 5 de novembro de 2026.

Esta política cobre o aplicativo ExplicAI, uma ferramenta interna que publica os vídeos do próprio canal nas contas oficiais do ExplicAI. Só o dono do canal usa o aplicativo. Ele não é oferecido ao público.

Dados que o aplicativo acessa

  • YouTube: com as permissões youtube.upload e youtube.readonly, envia vídeos ao canal do ExplicAI e lê os dados do próprio canal e dos vídeos enviados, como o identificador do canal e o status de processamento.
  • Instagram: pela API oficial, publica vídeos na conta @explicai.tv e lê o identificador da conta e o status da publicação.
  • TikTok: os vídeos são agendados pelo serviço Metricool, na conta do próprio canal.

O aplicativo não coleta dados de espectadores, seguidores ou de outras pessoas.

Como os dados são usados e guardados

Os dados são usados apenas para publicar os vídeos e confirmar que a publicação deu certo. As chaves de acesso ficam guardadas no computador do dono do canal, com acesso restrito. Os registros de publicação ficam no mesmo computador.

Os dados não são vendidos nem usados para publicidade. Eles também não são usados para treinar modelos de inteligência artificial.

Com quem os dados são compartilhados

Os dados só vão para os serviços necessários à publicação:

  • Google/YouTube e Meta/Instagram, que recebem os vídeos e as informações da publicação.
  • Metricool, que agenda a publicação no TikTok.
  • Litterbox, que hospeda temporariamente o arquivo do vídeo, por até 72 horas, para a entrega ao Instagram e ao Metricool. Esse arquivo fica acessível a quem tiver o link durante esse período.

As chaves de acesso não são enviadas a esses serviços, exceto ao próprio serviço que as emitiu.

Políticas e termos do Google e do YouTube

O aplicativo usa os serviços de API do YouTube. Ao usá-lo, valem os Termos de Serviço do YouTube e a Política de Privacidade do Google. O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso e excluir os dados

  • Google/YouTube: o acesso pode ser revogado em myaccount.google.com/permissions.
  • Instagram: o acesso pode ser removido nas configurações do Instagram, em "Apps e sites".
  • Dados locais: as chaves e os registros são excluídos do computador do dono do canal quando o aplicativo deixa de ser usado. Pedidos de exclusão podem ser feitos pelo contato abaixo.
